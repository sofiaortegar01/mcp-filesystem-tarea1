# 7. Casos de Uso Actuales

## Herramientas que implementan MCP
1. **Claude Desktop:** Cliente oficial que integra servidores MCP locales para interactuar con bases de datos, sistemas de archivos y APIs locales.
2. **Google Antigravity:** Entorno de desarrollo agéntico que utiliza protocolos contextuales para operar sobre bases de código y herramientas de desarrollo.
3. **Cursor / VS Code con extensiones MCP:** Editores que permiten a los asistentes de IA leer y modificar repositorios completos de manera estructurada sin intervención manual constante
